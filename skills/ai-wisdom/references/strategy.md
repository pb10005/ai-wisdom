# 戦略

努力の量ではなく向きを決めるための知恵。ユーザーのキャリア・事業・学習などの方針相談や、成果が出ないという悩みに向き合うときに使う。

### W-0006 予測できない成果は試行回数で量の問題に近づけ、当たった場は時間をかけないと積めないもので守る

- status: active
- tags: [戦略, 探索, 防御, 成果関数]
- 使う場面: 新しい取り組みの進め方や競争戦略を相談されたとき。着想頼みで成果が読めない仕事の計画を立てるとき。
- 指針:
  - いまの局面が「探索（非線形）」か「防御（線形）」かを見極め、打ち手を変える。
  - 探索の局面では、小さく多く試し、当たったものに資源を寄せる計画を提案する。
  - 当たりの場を見つけたら、データ・ネットワーク・ブランド・熟練など、時間をかけないと積めないものを積み上げて防御にする。
  - 量や時間の積み上げだけで競う計画には、相手も同じように積み上げられ優位が続かないこと、AI が「覚える」「時間を投入する」部分のコストを下げ続けていることを指摘する。
- 理由: 個々の着想は予測できないが、試行の回数は線形に増やせる。着想で得た場はすぐに真似されるが、時間をかけないと積めないものは後発が同じ時間をかけない限り追いつけない。強い戦略は探索→防御→（前提のコモディティ化）→再探索の循環を回し続ける。
- 例外・注意: 一度の失敗を責める評価制度の下では「小さく多く試す」は機能しない。戦略を変えるなら評価の仕組みも同時に変える必要があることを伝える。
- 出典: [量で競う人、組み合わせで競う人 ― 経験が形づくる競争観とその摩擦](../../../essays/2026/2026-10-07-quantity-vs-combination.md)

### W-0007 努力を積み増す前に、勝利条件・評価者・実際のルールを確かめる

- status: active
- tags: [戦略, 評価, 努力]
- 使う場面: ユーザーが「頑張っているのに報われない」と言うとき。成果を出すための計画や努力の配分を相談されたとき。
- 指針:
  - 次の三つを一緒に確認する: 何を達成すれば勝ちか（勝利条件）／誰が何を見て判定しているか（評価者）／建前ではなく実際に報酬が集まっている行動は何か、過去に勝った人は何をしていたか（実際のルール）。
  - ユーザーの努力のうち「得点板に載っているもの」と「載っていないもの」を分けて示す。
  - 答えが分からない問いがあれば、それを知ることを最初の仕事として提案する。
- 理由: 報われない努力の多くは量ではなく向きの問題で、別のゲームの得点になっている。例えば丁寧な資料作りに時間をかける人が、実は意思決定の速さで評価される組織にいる。ルールを確かめずに頑張るのは、地図を持たずに全力で走るのと変わらない。
- 例外・注意: ルールは変わり、評価者も入れ替わる。一度確かめて終わりにせず、定期的に確かめ直すことを勧める。
- 出典: [努力の前に、ゲームを選べ](../../../essays/2026/2026-10-07-choose-the-game.md)

### W-0009 構造的に勝てない場を見抜き、撤退や場の変更を合理的な選択肢として示す

- status: active
- tags: [戦略, 撤退, 比較優位]
- 使う場面: 長く続けても状況が変わらないという相談。競争の激しい場での戦い方を聞かれたとき。
- 指針:
  - 次のサインがないかを確認する: 上位との差が努力の量ではなく資本・立場・先行した時間などの初期条件で決まっている／何年続けても評価やリターンの伸びがほとんど変わらない／自分の得意なことがその場では価値を生まない。
  - サインがあれば、弱みの克服を続けるより、強みが相対的に生きる場所・競争相手が少ない場所・ルールが有利な場所へ移る選択肢を示す（比較優位）。
  - 撤退を敗北として扱わず、勝てる場所に時間と力を移す一手として説明する。
- 理由: 構造的に不利なゲームでは、努力しても勝率がわずかに上がるだけで結果はほとんど覆らない。撤退を決められる人ほど次のゲームで勝つ確率が高い。
- 例外・注意: 撤退するかどうかはユーザーが決める。続けることに本人が別の価値を置いている場合はそれを尊重し、判断材料を示すに留める。
- 出典: [努力の前に、ゲームを選べ](../../../essays/2026/2026-10-07-choose-the-game.md)

### W-0010 やることを増やす前に、やらないことを決める

- status: active
- tags: [戦略, 優先順位, 集中]
- 使う場面: タスクや施策の計画を立てるとき。ユーザーがすべてに全力を出そうとしているとき。
- 指針:
  - 「いまやっていることのうち、やめても結果が変わらないものは何か」を洗い出し、やめる候補として示す。
  - 限られた時間と力を集中させる先を一つか少数に絞った案を出す。
  - 「どう戦うか（戦術）」を磨く前に、「どこで、何のために戦うか（戦略）」が合っているかを確かめる。
- 理由: 使える時間も力も限られている。すべてに力を配れば、どこでも平凡な結果しか残らない。戦略を誤ると戦術では取り返せない（間違った山をどれだけ速く登っても目的地には着かない）。
- 例外・注意: やめる判断はユーザーの価値観に関わる。候補を示し、決定はユーザーに委ねる。
- 出典: [努力の前に、ゲームを選べ](../../../essays/2026/2026-10-07-choose-the-game.md)

### W-0028 続く事業や資産の価値は、年にいくら稼ぐかより、何年稼ぎ続けるか（減衰率）で評価する

- status: active
- tags: [戦略, 評価, 減衰率, 継続性]
- 使う場面: 作品・ブランド・サービス・事業の価値を比べるとき。売上を伸ばす施策と、離脱や衰えを止める施策のどちらに力を入れるか相談されたとき。
- 指針:
  - 年間の稼ぎだけで比べず、毎年どれだけ縮むか（減衰率）・伸びるかを見積もる。価値はおおむね「年間キャッシュフロー ÷（割引率 + 減衰率 − 成長率）」で表せ、倍率（マルチプル）はこの分母の逆数になる。
  - 減衰率の数字の差が評価の差を大きく動かすことを示す（割引率10%のとき、毎年15%縮めば4倍、横ばいなら10倍、毎年3%伸びれば約14倍。同じ年10億円でも40億円にも140億円にもなる）。
  - 終わりが決まっているものは、永続ではなく残りの年数で計算する。
  - 価値を上げる方法として、売上を伸ばすことより減衰を止めることを先に検討する。
- 理由: 評価の差の大半は減衰率から生まれる。減衰率を左右するのは、新しい中身が出続けるか、特定の個人がいなくても続くか、収益源が分かれているか、顧客との接点を自社で持っているかである（W-0029、W-0031）。
- 例外・注意: 式は簡易版で、実務の正式な評価ではロイヤルティ免除法などが使われる（考え方は同じ）。減衰率や寿命は見積もりなので、幅を持たせて示す。

### W-0029 続くかどうかは、「中身が補給され続けるか」と「特定の作り手がいなくても続くか」の掛け算で見立てる

- status: active
- tags: [戦略, 継続性, 属人性, リスク]
- 使う場面: 作品・サービス・プロジェクト・チームの寿命や継続性を見立てるとき。長期の投資や計画の前提を確かめるとき。
- 指針:
  - 補給の頻度を確かめる: 顧客やファンが追いかける理由が、どれくらいの間隔で新しく生まれているか。長い空白期間に、つなぎとめる仕掛けがあるか。
  - 作り手からの独立度を確かめる: その人が抜けたら成り立たない、という一人への依存がないか。
  - どちらかが弱ければ、それを補う手（短い補給の企画、作り手以外でも作れる体制づくり）を提案する。
- 理由: 日々更新される原作があれば追いかける理由が毎日生まれ、関連する展開の文脈も途切れない（ちいかわ）。3年の空白期間があり、終わりが決まり、原作・演出・プロデュースを一人が担う作品は、両方とも弱い（VIVANT）。両方を満たしていても、作者一人への依存が残れば、それが寿命の上限を抑える。
- 例外・注意: 補給しすぎると希少性が落ち、一回あたりの熱が下がる（W-0032）。
- 出典: [IPビジネスの次の一手：ちいかわとVIVANTで考える](../../../essays/2026/2026-11-13-ip-business-next-move.md)

### W-0030 固定費の大きい投資は、回収期間が見込み寿命の半分以内に収まるかで判断し、読めなければ小さく分ける・分け合う・期間を限る

- status: active
- tags: [戦略, 投資判断, 固定費, 回収期間]
- 使う場面: 施設・設備・大型システム・長期契約など、初期投資と維持費が重い打ち手を検討するとき。
- 指針:
  - 投資を固定費型（施設・直営）か変動費型（ライセンス・委託）かに分け、判断の軸を変える。
  - 固定費型は、回収期間が対象の見込み寿命より十分に短いかを確かめる。目安は寿命の半分以内。
  - 寿命が読めないときは、固定費を小さく分ける（小型施設から始める）、他社と分け合う（既存の施設の一区画に入る）、期間を限る（短期で回収して撤収できる形）のいずれかを提案する。
  - 段階を踏む順番を示す: 小さく始めて早く回収する → 固定費を分け合う形で広げる → 寿命の不安が解けてから単独の大型投資を考える。
- 理由: 大きな固定費の回収には10年単位の時間がかかる。完結が決まっているものに常設の施設を作ると、終わったあとに維持費だけが残る。寿命が読めない初期には、外れても損が小さいライセンスのような変動費型が向く。
- 例外・注意: 「寿命の半分以内」はエッセイが示す目安で、業種や金利によって調整が要る。

### W-0031 顧客との接点とデータは自社で持ち、仲介に任せきりにしない

- status: active
- tags: [戦略, 顧客接点, データ, 直販]
- 使う場面: 販売・配信・展開の方法を選ぶとき。外部のプラットフォームや代理店、ライセンス先に任せる案を検討するとき。
- 指針:
  - 売上だけでなく、誰が顧客との関係とデータを持つことになるかを比べる。
  - 仲介や委託は入口として使い、会員基盤・自社EC・直営の場など、顧客と直接つながる経路を並行して持つ案を示す。
  - 任せる場合は、そこで得られなくなるもの（顧客データ、利益率、関係の継続）を明示する。
- 理由: 価値は作品そのものより、誰が顧客との関係を持っているかで決まるようになっている。直営店と自社ECで回収の出口を持つ形は国内で成功したが、海外の展開をライセンスに任せると、海外の顧客のデータが自社に残らない。配信権の収入が大きくても、視聴データと関係が外にあれば、作品が終わったあとに居場所を残せない。時間をかけて積んだ顧客との関係は、後発が追いつきにくい防御にもなる（W-0006）。
- 例外・注意: 直営や自社ECは在庫などのリスクを負う。寿命が読めない初期は、損の小さい委託から始める判断もある（W-0030）。

### W-0032 離脱を減らすには、顧客がどの段階で抜けているかを見て、段階ごとに戻ってくる理由を作る

- status: active
- tags: [戦略, リテンション, 顧客, 測定]
- 使う場面: サービス・作品・コミュニティの継続率を上げたいと相談されたとき。施策の数を増やしたくなったとき。
- 指針:
  - 顧客の段階を「認知 → 初めての接触 → 習慣化 → 深化 → 休眠 → 復帰」に分け、どこで人が抜けているかを先に確かめる。
  - 段階ごとに手を変える: 習慣化では接触の間隔を短くする／深化では段差の小さい関与の階段（無料 → 低単価 → 高単価 → 体験）を用意する／顧客同士のつながりの場を作る／休眠した人には戻る入口（周年企画・続編前の無料公開など）を作る／新しい人の入口を絶やさない。
  - 効果は、時期ごとに入った顧客が半年後・1年後に何割残っているか（コホート別の残存率）、残存率が下げ止まる水準、再購入率と接触の間隔で測る。
- 理由: 減衰は離脱と新しい流入の差で決まる。人は思い出す理由がないと離れるので、補給の頻度がいちばん効く。上の段にいる人ほど離れにくく、作品より仲間が残る理由になる。
- 例外・注意: やりすぎると逆効果になる。出しすぎると希少性が落ちる。搾り取るような課金は短期の売上を上げても不信を招き、減衰を早める。古くからの顧客に偏ると新しい人が入りにくくなる。
- 出典: [IPビジネスの次の一手：ちいかわとVIVANTで考える](../../../essays/2026/2026-11-13-ip-business-next-move.md)
