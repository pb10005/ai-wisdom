# 教訓かるた

AI エージェント向けの知恵（`skills/ai-wisdom/`）を、人が教訓として読めるように書き直したもの。
一つの知恵を、次の四つで一枚の札にしている。

- **格言**: 一行で覚えられる言葉
- **寓話**: 教訓を伝える短い話（創作。出典のエッセイに登場する話ではない）
- **教訓**: 格言の意味を平易に言い直したもの
- **問い**: 明日の自分に投げかける問い

札をめくって読むには `index.html`（カード形式のページ）を開く。Markdown のまま読んでもよい。

## 更新のしかた

知恵カードを追加したら、同じ番号の札を該当テーマのファイルに書き、ページを作り直す。

```sh
python3 scripts/build_lessons.py   # index.html を作り直す
python3 scripts/check.py           # 知恵カードと札が一対一でそろっているかを確かめる
```
