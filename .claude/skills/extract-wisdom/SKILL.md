# エッセイから知恵を抽出する

エッセイ（一次資料）から、エージェントが行動指針として使える知恵を取り出し、
`skills/ai-wisdom/` に反映する。

## 知恵とは何か

抽出してよいのは次を満たすものだけ。

- **行動に変換できる**: 「〜のときは〜する」と書ける。感想・事実の記述だけのものは対象外。
- **一般化できる**: そのエッセイの個別事情を外しても成り立つ。
- **根拠がエッセイにある**: エッセイに書かれていない主張を足さない。推測で補った部分は「例外・注意」に明記する。

1 本のエッセイから 0〜5 個程度が目安。無理に出さない（0 個でもよい）。

## 手順

### 1. 対象を決める

- ユーザーがエッセイを指定したらそれを対象にする。
- 指定がなければ `python3 scripts/check.py --pending` で `extracted: false` のエッセイを一覧し、すべてを対象にする。

### 2. 既存の知恵を把握する

- `skills/ai-wisdom/SKILL.md` の索引と、関係しそうな `references/*.md` を読む。
- 次に振る ID は `python3 scripts/check.py --next-id` で確認する。

### 3. 候補を書き出す

各エッセイを読み、候補ごとに以下を整理する。

- 原則（一文、命令形か「〜する」で終える）
- 使う場面（エージェントがこのカードを思い出すべき状況）
- 指針（具体的に何をするか。箇条書き可）
- 理由（エッセイが示す根拠）
- 例外・注意（当てはまらない場面、誤用の危険）

### 4. 既存カードと突き合わせる

| 状況 | 対応 |
| --- | --- |
| 新しい知恵 | 新しい ID で追加 |
| 既存カードと同じ主張 | 新カードは作らず、既存カードの「出典」にエッセイを追記し、必要なら理由・例外を補強 |
| 既存カードを精緻化する | 既存カードを更新（ID は維持） |
| 既存カードと矛盾する | 勝手に解消しない。両論をユーザーに提示して判断を仰ぐ |

### 5. カードを書く

- テーマに合う `skills/ai-wisdom/references/<theme>.md` に追記する。合うものがなければ新しいテーマファイルを作る（ファイル名は英小文字・ハイフン、見出しは日本語）。
- カードの書式は厳守（`scripts/check.py` が検査する）:

```markdown
### W-0001 原則を一文で

- status: active
- tags: [タグ1, タグ2]
- 使う場面: エージェントがこの知恵を使うべき状況
- 指針:
  - 具体的な行動 1
  - 具体的な行動 2
- 理由: なぜそうするのか
- 例外・注意: 当てはまらない場面
- 出典: [エッセイのタイトル](../../../essays/2026/2026-10-07-slug.md)
```

- カードは単体で意味が通るように書く（skill はリポジトリ外にコピーされ、出典リンクが辿れない状態で読まれることがある）。
- エージェントに向けて書く。「ユーザーに〜を確認する」のように、エージェント自身の行動として書く。

### 6. 索引を更新する

`skills/ai-wisdom/SKILL.md` の「索引」表に、テーマファイルと含まれる知恵（ID と原則の一文）を反映する。
SKILL.md 本体には知恵の詳細を書かない。

### 7. 人向けの教訓を書く

追加した知恵ごとに、同じ ID の札を `lessons/<theme>.md`（テーマは知恵カードと同じファイル名）に書く。書式は厳守（`scripts/check.py` が検査する）:

```markdown
### W-0001 一行で覚えられる格言

- 寓話: 寓話のタイトル

> 3〜5 文の短い寓話。人物や動物、村や店などの身近な舞台で、教訓が一つの出来事として見える話にする。

- 教訓: 格言の意味を平易に言い直す（1〜3 文）。知恵カードの主張から外れない。
- 問い:
  - 読み手が自分に投げかける問い（2〜3 個）
- 出典: [エッセイのタイトル](../essays/2026/2026-10-07-slug.md)
```

- 読み手は人。エージェント向けの指示文（「ユーザーに確認する」など）にしない。
- 格言は短く（20 字前後まで）。カードでは縦書きで表示される。
- 寓話は創作でよいが、教訓と問いはエッセイの主張に沿わせる。エッセイに出てくる例をそのまま使ってもよい。
- 既存カードを更新・廃止したら、札も合わせて直す（廃止したカードの札は消す）。
- 書いたら `python3 scripts/build_lessons.py` で `lessons/index.html` を作り直す。

### 8. エッセイを抽出済みにする

対象エッセイの frontmatter を `extracted: true`、`wisdom: [W-xxxx, ...]` に更新する（知恵が 0 個なら `wisdom: []` のまま `extracted: true`）。本文は変更しない。

### 9. 検証と報告

- `python3 scripts/check.py` と `python3 scripts/build_lessons.py --check` が通ることを確認する。
- 追加・更新したカードの一覧（ID・原則・出典）と、判断を保留した矛盾があればそれをユーザーに報告する。
